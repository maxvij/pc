# FormD T1 build plan

A compact 1440p gaming PC in a silver NCASE FormD T1, planned and bought one part at a time.

- `index.html`: parts ledger with second-hand, middle and high-end options per part, live totals, NZD/EUR switch and cost over time.
- `primer.html`: catch-up notes on DDR5, AM5, PCIe 5.0, Mini-ITX and quiet tuning.

Static site, no build step. Served with GitHub Pages from the `main` branch root.
